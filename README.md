# Hospital Performance Dashboard

## Project Overview
This project focuses on analyzing hospital performance, financial, and operational data using Power BI to explore patient encounters and revenue trends through an interactive dashboard.

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Data Cleaning
- Data Visualization

## Project Files
- Power BI Dashboard (.pbix)
- Excel Dataset (.xlsx)
- Dashboard Screenshots

Screenshots of the dashboard (`Hospital Performance`, `Financial Overview`, and `Operations & Efficiency`) are available in the repository.

- Financial Overview & Revenue Analysis
